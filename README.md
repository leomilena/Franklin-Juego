# El detective Franklin y el caso del Rompecabezas

Juego de investigación noir en el Nueva York de 1948, basado en la novela de Leo Milena.

**Jugar:** https://leomilena.github.io/Franklin-Juego/

En iPad: abre el enlace en Safari, pulsa **Compartir → Añadir a pantalla de inicio** y juega a pantalla completa, también sin conexión.
